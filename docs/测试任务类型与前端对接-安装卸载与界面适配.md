# 测试任务类型与前端对接说明（安装卸载升级测试、界面与适配测试）

## 一、新增任务类型（后端已支持）

| 任务类型枚举值 | 显示名称 | 说明 |
|----------------|----------|------|
| `INSTALL_UNINSTALL_UPGRADE_TEST` | 安装卸载升级测试 | 应用安装、卸载与升级流程验证 |
| `UI_ADAPTATION_TEST` | 界面与适配测试 | 界面展示与多分辨率适配检查 |

与现有类型（如 `FUNCTIONAL_QUALITY_TEST`、`COMPATIBILITY_TEST`）一样，**会出现在「测试任务」列表与任务详情中**，对接方式一致。

---

## 二、前端对接方式（与现有测试任务一致）

### 1. 获取可执行场景列表（自动化测试列表）

**接口：** `GET {baseUrl}/functional-test/scenarios`

**用途：** 展示「可点击执行的测试场景」，用户选择设备/应用后点击「执行」时，用对应 `scenarioId` 调用执行接口。

**响应示例（节选新增项）：**

```json
[
  { "id": "login_android", "name": "登录测试(Android)", "platform": "ANDROID", "taskType": "FUNCTIONAL_QUALITY_TEST", "description": "..." },
  { "id": "compatibility_android", "name": "兼容性测试(Android)", "platform": "ANDROID", "taskType": "COMPATIBILITY_TEST", "description": "..." },
  { "id": "install_upgrade_android", "name": "安装卸载升级测试(Android)", "platform": "ANDROID", "taskType": "INSTALL_UNINSTALL_UPGRADE_TEST", "description": "Android 应用安装、卸载与升级流程验证" },
  { "id": "install_upgrade_ios", "name": "安装卸载升级测试(iOS)", "platform": "IOS", "taskType": "INSTALL_UNINSTALL_UPGRADE_TEST", "description": "iOS 应用安装、卸载与升级流程验证" },
  { "id": "ui_adapt_android", "name": "界面与适配测试(Android)", "platform": "ANDROID", "taskType": "UI_ADAPTATION_TEST", "description": "Android 界面展示与多分辨率适配检查" },
  { "id": "ui_adapt_ios", "name": "界面与适配测试(iOS)", "platform": "IOS", "taskType": "UI_ADAPTATION_TEST", "description": "iOS 界面展示与多分辨率适配检查" }
]
```

**前端建议：**

- 按 `platform` 过滤当前端设备平台（ANDROID / IOS），只展示对应场景。
- 按 `taskType` 或 `name` 做分组/标签（如「登录测试」「兼容性测试」「安装卸载升级测试」「界面与适配测试」）。

---

### 2. 一键执行（创建任务并立即执行）

**接口：** `POST {baseUrl}/functional-test/execute`

**请求体：**

```json
{
  "scenarioId": "install_upgrade_android",
  "deviceId": "设备ID",
  "applicationId": "应用ID",
  "config": ""
}
```

| scenarioId | 说明 |
|------------|------|
| `install_upgrade_android` | 安装卸载升级测试(Android) |
| `install_upgrade_ios` | 安装卸载升级测试(iOS) |
| `ui_adapt_android` | 界面与适配测试(Android) |
| `ui_adapt_ios` | 界面与适配测试(iOS) |

`deviceId`、`applicationId` 必填，来源与登录测试相同（设备列表、该设备下的应用列表）。`config` 可选，当前两种新类型可不传。

**响应：** 与现有一致，返回 `taskId`、`status`、`message`，前端用 `taskId` 轮询任务状态。

---

### 3. 测试任务列表（含新类型）

**接口：** `GET {baseUrl}/functional-test/tasks?status=&keyword=&days=&page=1&size=10`  
分页参数：`page`（从 1 开始）、`size`（每页条数，默认 10，最大 100）。响应为分页对象：`content`（当前页任务数组）、`totalElements`、`totalPages`、`page`、`size`。

**说明：** 列表已包含「安装卸载升级测试」「界面与适配测试」任务，与功能测试、兼容性测试同接口、同分页筛选。

**响应项中与类型相关的字段：**

- `taskType`：`FUNCTIONAL_QUALITY_TEST` \| `COMPATIBILITY_TEST` \| `INSTALL_UNINSTALL_UPGRADE_TEST` \| `UI_ADAPTATION_TEST`
- 其他字段不变：`id`、`taskName`、`remarks`、`platform`、`deviceId`、`applicationId`、`deviceName`、`status`、`createdAt` 等。

**前端建议：**

- 用 `taskType` 做标签/筛选，显示「安装卸载升级测试」「界面与适配测试」等中文名称（可维护枚举到中文的映射）。
- 列表、卡片样式与现有任务一致即可。

---

### 4. 任务详情（含新类型）

**接口：** `GET {baseUrl}/functional-test/tasks/{id}`

**说明：** 当任务类型为 `INSTALL_UNINSTALL_UPGRADE_TEST` 或 `UI_ADAPTATION_TEST` 时，同样返回 200 与完整任务详情（不再 404）。

**响应字段：** 与现有一致，包含 `taskType`、`executionStatus`、`reportPath`、`errorMessage`、`resultData`、`executionEndTime` 等。

---

### 5. 停止 / 删除任务

与现有测试任务相同：

- 停止：`POST {baseUrl}/functional-test/tasks/{id}/stop`
- 删除：`DELETE {baseUrl}/functional-test/tasks/{id}`

## 四、当前后端执行说明

- **安装卸载升级测试**、**界面与适配测试**：后端已创建任务并支持执行入口，执行时会标记为「执行中」并正常结束（当前为占位逻辑，后续会接入真实安装/卸载/升级与界面适配脚本）。
- 任务状态、列表、详情、停止、删除的接口行为与现有功能测试、兼容性测试一致，前端只需按 `taskType` 展示不同标签/名称即可。

---

## 五、前端自检清单

- [ ] 场景列表：能展示「安装卸载升级测试(Android/iOS)」「界面与适配测试(Android/iOS)」，且按平台过滤。
- [ ] 执行：选择上述场景后，能传对应 `scenarioId`（如 `install_upgrade_android`、`ui_adapt_ios`）调用 `POST /functional-test/execute`。
- [ ] 任务列表：列表中能看到这两种类型的任务，且 `taskType` 正确。
- [ ] 任务详情：点击这两种任务可进入详情页，接口返回 200 且数据完整。
- [ ] 展示名称：列表/详情中用中文展示「安装卸载升级测试」「界面与适配测试」。
