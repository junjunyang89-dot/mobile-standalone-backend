# 接口测试 + URL 管理 + 项目管理

## 菜单位置（资产管理一级，不在「完美世界电竞」下）

| 模块 | 路径 |
|------|------|
| **项目管理** | 资产管理 → 项目管理 |
| **URL 管理** | 资产管理 → URL 管理 |
| **接口测试** | 功能测试 → 接口测试 |

## 关系

```
项目 (api_projects.code)
  ├── URL（网关 Base URL，按测/线）
  └── 接口用例（method + path，下拉绑定 URL）
```

执行：`URL.baseUrl` + `用例.path`。

## data-center

启动种子：项目 `data-center`、测试/线上网关 URL、接口用例清单。  
旧丑陋用例名可在接口测试页点「重导 data-center」。
