## 五、我要改的流程

以后每次声称"编译通过"之前,先跑一次镜像新鲜度校验:

```
对你的 src/main/java 和 src/test/java 做 md5 清单
→ 和我的镜像逐文件比
→ 有任何 缺失 / 不一致 就先同步，再编译
→ 差异不为 0 时不允许说"编译通过"
```

这次我就是靠这个才发现漂了 38 个文件。**它应该是每次编译前的前置步骤,
而不是出了问题才想起来做的排查手段。**

还有一个我踩到的坑值得记一下:`src/test/java/com/mobile/standalone/service/apitest/`
