# 「设置」自动化测试 - 当前实现说明

便于与旧项目 automation-service-standalone 对照，确认是否缺步骤或定位器。

---

## 一、整体流程（按执行顺序）

| 序号 | 步骤 | 说明 |
|------|------|------|
| 1 | 环境校验 | 应用存在、包名含 `steam.esports`、Appium 已开启 |
| 2 | 启动应用 | `platformDriver.launchApp(deviceId, packageOrBundle)`，建立 Appium 会话 |
| 3 | 等待 3 秒 | 启动后稳定 |
| 4 | 获取 AppiumDriver | `appiumDriverAdapter.getAppiumDriver(deviceId)` |
| 5 | **点击侧边栏** | 打开侧边栏，等待约 2 秒 |
| 6 | **是否已登录** | 在约 4 秒内等待「主页」元素（如 `tv_mine_homepage`）。若出现则视为已登录；否则视为未登录。 |
| 7a | **已登录** | 记录「已登录，跳过登录步骤」→ 直接执行：验证已登录(主页) → 点击设置入口 → 验证进入设置页面 → （设置-我的账号场景再进入我的账号）→ 截图 |
| 7b | **未登录** | 关闭侧边栏 → 记录「未登录，执行登录流程」→ 执行完整登录（温馨提示/侧边栏/手机号/验证码）→ 再执行：点击侧边栏 → 验证已登录(主页) → 点击设置 → 验证设置页 → （设置-我的账号再进入我的账号）→ 截图 |
| 8 | 设置页/我的账号页截图 | 截图保存并写入执行日志 |
| 9 | 返回结果 | `FunctionalTestExecutionResult(reportPath, executionLog, null)` |

## 二、Android 设置页步骤（runAndroidSettingsFlow）

| 序号 | 步骤名（执行日志） | 操作 | 定位器 |
|------|---------------------|------|--------|
| 1 | 点击侧边栏 | 等待并点击侧边栏按钮 | `id: com.pwrd.steam.esports:id/sideView` |
| (等待 2 秒) | - | - | - |
| 2 | 验证已登录(主页) | 等待「主页」元素出现 | `xpath: //android.widget.TextView[@resource-id='com.pwrd.steam.esports:id/tv_mine_homepage']` |
| 3 | 点击设置入口 | 等待并点击「设置」 | `xpath: //android.widget.TextView[@resource-id='com.pwrd.steam.esports:id/tv_tool_mame' and @text='设置']` |
| (等待 2 秒) | - | - | - |
| 4 | 验证进入设置页面 | 等待设置页标题出现 | `xpath: //android.widget.TextView[@resource-id='com.pwrd.steam.esports:id/tv_title']` |

之后在设置页截图（见整体流程第 8 步）。

**已定义但当前未在流程中使用的 Android 定位器：**

- `SideMenu.CLICK_LOGIN`：`//android.widget.TextView[@text='点击登录']`
- `SettingsPage.LOGOUT_BUTTON`：`//android.widget.TextView[@resource-id='com.pwrd.steam.esports:id/tv_logout']`

## 四、「设置-我的账号」自动化测试（scenarioKey=settings_account）

与「设置」共用前置：启动应用 → 登录 → 进入设置页（侧边栏 → 设置 → 验证设置页）。在此基础上追加：

| 序号 | 步骤名（执行日志） | 操作 | 定位器（Android 示例） |
|------|---------------------|------|------------------------|
| 1 | 点击我的账号 | 在设置页内点击「我的账号」 | `xpath: //android.widget.TextView[@text='我的账号']` |
| 2 | 验证进入我的账号页面 | 等待我的账号页特征元素 | `xpath: //android.widget.TextView[contains(@text,'账号') or contains(@text,'手机')]` |
| 3 | 我的账号页截图 | 截图保存到 `settings_account_{taskId}_{timestamp}.png` | - |

- **场景键**：创建任务时传 `scenarioKey: "settings_account"`。
- **定位器**：Android 见 `SettingsLocators.SettingsPage.MY_ACCOUNT`、`MyAccountPage.PAGE_TITLE`；iOS 见 `locators/ios/settings/SettingsLocators` 同名枚举。

## 八、小结

- **设置测试**（`scenarioKey=settings`）：启动应用 → **若已登录则跳过登录**，否则执行登录 → 点击侧边栏进入设置页 → 在设置页截一张图。
- **设置-我的账号测试**（`scenarioKey=settings_account`）：同上，进入设置页后再点击「我的账号」→ 验证我的账号页 → 在我的账号页截一张图。
- **设置-我的兴趣测试**（`scenarioKey=settings_interests`）：同上，进入设置页后再点击「我的兴趣」→ 验证我的兴趣页 → 在我的兴趣页截一张图。
- **设置-高校认证测试**（`scenarioKey=settings_school_cert`）：同上，进入设置页后再点击「高校认证」→ 验证高校认证页 → 在高校认证页截一张图。

若你记得旧项目里还有「进入设置/我的账号/高校认证后」的更多步骤，可以说一下具体步骤或旧代码位置，我可以按当前结构补上。
