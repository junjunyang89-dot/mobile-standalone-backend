# 任务详情：手机号 / 验证码变量 - 前端对接说明

功能体验基础质量测试（登录测试）执行后，前端需要展示**脱敏后的手机号、验证码**，便于在「检测规则」表格的「详细日志」列或执行日志中查看。后端已提供完整对接数据。

---

## 一、数据从哪里拿

### 方式一：任务详情概览（推荐，一次拿全）

**接口：** `GET {baseUrl}/functional-test/tasks/{id}/overview`

**响应中与变量相关的字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| **executionVariables** | `Object` | 执行变量脱敏值。键：`phoneNumberMasked`、`verificationCodeMasked`；值示例：`"138****8000"`、`"****(6位)"` |
| **testResultItems[].detailMessage** | `String` | 检测规则表格「详细日志」列可直接展示的文案。仅「输入手机号」「输入验证码」两行有值，其余为 `null` |

**示例：**

```json
{
  "executionVariables": {
    "phoneNumberMasked": "138****8000",
    "verificationCodeMasked": "****(6位)"
  },
  "testResultItems": [
    { "testItemCategory": "登录", "testItemName": "输入手机号", "testResult": "通过", "detailLogLink": null, "detailMessage": "138****8000" },
    { "testItemCategory": "登录", "testItemName": "输入验证码", "testResult": "通过", "detailLogLink": null, "detailMessage": "****(6位)" },
    { "testItemCategory": "登录", "testItemName": "完成登录", "testResult": "通过", "detailLogLink": null, "detailMessage": null }
  ]
}
```

### 方式二：任务详情

**接口：** `GET {baseUrl}/functional-test/tasks/{id}`

**响应中与变量相关的字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| **executionVariables** | `Object` | 同上，`phoneNumberMasked`、`verificationCodeMasked` |

未执行或非登录测试时，`executionVariables` 可能为 `null`。

---

## 二、前端如何展示

### 1. 检测规则表格「详细日志」列

- 数据源：**overview** 的 **testResultItems**。
- 每一行：
  - 若 **detailMessage** 有值（如「输入手机号」「输入验证码」）：直接显示 `detailMessage`（即脱敏手机号、验证码文案）。
  - 若 **detailMessage** 为 `null`：可显示「-」或「查看」链接（用 `detailLogLink` 若有）。

这样前端无需再根据 testItemName 去匹配，后端已按行填好 **detailMessage**。

### 2. 执行日志面板

- 数据源：**executionLog**（任务详情或 `GET .../tasks/{id}/execution-log`）。
- 每条日志的 **message** 中已包含变量描述，例如：
  - 输入手机号：`"已输入: 138****8000"`
  - 输入验证码：`"已输入: ****(6位)，等待登录完成"`
- 前端按「时间 + Level + message」展示即可，无需再拼变量。

### 3. 其他需要单独用变量的地方

- 若某处只需「手机号/验证码」两个值，可直接用 **executionVariables**：
  - `executionVariables.phoneNumberMasked`
  - `executionVariables.verificationCodeMasked`
- 无执行或非登录任务时为 `null`，前端做空值判断即可。

---

## 三、脱敏规则说明

| 变量 | 脱敏方式 | 示例 |
|------|----------|------|
| 手机号 | 前 3 位 + **** + 后 4 位 | `138****8000` |
| 验证码 | 不展示明文，仅展示位数 | `****(6位)` |

---

## 四、小结

| 需求 | 推荐数据来源 | 使用字段 |
|------|--------------|----------|
| 检测规则表格「详细日志」列 | overview | **testResultItems[].detailMessage** |
| 执行日志里看到手机号/验证码 | executionLog | 每条 **message** 已含脱敏文案 |
| 仅取手机号、验证码两个值 | overview 或 task 详情 | **executionVariables** |

按上表对接即可完整拿到并展示手机号、验证码的脱敏值。
