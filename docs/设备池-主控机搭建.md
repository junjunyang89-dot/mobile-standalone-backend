# 设备池主控机搭建（Android AVD + iOS Simulator + 鸿蒙模拟器）

给要搭一台「大家共用、不用自己插手机」的机器看。看完应能：装好工具、建好虚拟机、自检通过、在设备池里点启动，真机和模拟器一起排队轮转。

前提：后端 `role=ALL` 跑在这台常开机器上。设备不跨机器路由。

---

## 先说用法，再装东西

模拟器**常驻**，跟真机一样进设备池轮转。

| 你想做的 | 正确做法 | 别这么做 |
| --- | --- | --- |
| 跑自动化 / 调试 | 保持开着，让调度器派活 | 用完就关（下次冷启动 30～60 秒，夜里没人点启动） |
| 环境脏了（登录态、弹窗） | 「清数据」或 `pm clear` | 关机再开——并不更干净，只更慢 |
| 腾内存、某台卡死、临时加一台 | 设备池里点关闭 / 启动 | — |

同时开着的虚拟机默认最多 **4** 台（`app.emulator.max-running`）。一台 AVD 大约 2～4GB，再加后端、adb、Appium。超了不会有明确报错，表现是整机变慢、用例大面积超时。

**能干和不能干：**

| 场景 | 模拟器 / Simulator |
| --- | --- |
| 元素点选、流程试跑、测试环境功能回归 | 可以 |
| 生产环境巡检、性能测试、上线前最终回归 | 不行（平台会拦）。要真机 |

雷电 / 夜神：`adb` 能扫到就能跑用例，但平台**管不了启停**（问不出 AVD 名）。要在设备池里点启动，必须用 Android Studio 官方模拟器。

iOS **真机**仍然要 USB、信任、WDA 签名。这份文档里的 iOS 是 **Simulator**，和 Android AVD 对等。

鸿蒙 **真机**走 hdc，见 `docs/鸿蒙hdc自动化.md`。这份文档里的鸿蒙是 **DevEco Phone Emulator**，和 AVD / Simulator 对等：设备池里能列出、能启停、能清数据。

---

## 机器要什么样

- **macOS**，建议 Apple 芯片（arm64）。Android 镜像选 `arm64-v8a`，别选 x86_64。
- 内存：真机几台 + 常驻 1～2 台虚拟机，建议 **32GB** 起。16GB 只能硬撑一台。
- 磁盘：Android 系统镜像 + AVD 数据轻松十几 GB。
- 这台要**常开**。后端停了，设备池、排队、启停都停。

## 一、公共命令行

终端里这些命令都要能直接跑（给**后端进程**用，不只给你当前窗口用）：

```bash
adb version
emulator -list-avds
xcrun simctl list devices available
idevice_id -l          # iOS 真机，没有真机也可以先没有
hdc list targets
# 鸿蒙模拟器（DevEco 自带，不要和 Android 的 emulator 搞混）
/Applications/DevEco-Studio.app/Contents/tools/emulator/Emulator -list
```

`~/.zshrc` 最少要有：

```bash
export ANDROID_HOME=$HOME/Library/Android/sdk
export ANDROID_SDK_ROOT=$ANDROID_HOME
export PATH=$ANDROID_HOME/emulator:$ANDROID_HOME/platform-tools:$PATH
```

改完 **新开一个终端**，或 `source ~/.zshrc`。

注意：IDE / launchd 拉起的后端往往带不上你终端的 PATH。平台会再去 `$ANDROID_HOME/emulator/emulator` 和 `~/Library/Android/sdk` 找。找不到时设备池会提示「找不到 emulator 命令」——这时先确认 SDK 路径，再**重启后端**（只刷新前端不够）。

## 二、Android（官方 AVD）

### 1. 装 SDK

装 [Android Studio](https://developer.android.com/studio)。SDK 装完应有：

```text
~/Library/Android/sdk/emulator/emulator
~/Library/Android/sdk/platform-tools/adb
~/Library/Android/sdk/system-images/...
```

### 2. 建 AVD

Android Studio → **Device Manager** → **Create Device**：

1. 选一台手机（Pixel 7 / Medium Phone 均可）
2. 系统镜像：Apple 芯片选 **arm64-v8a**；要登录 Google 相关能力再勾 Play Store
3. 名字记下来，例如 `Medium_Phone_API_36.1`——设备池「启动」用的就是这个名字

建完自检：

```bash
emulator -list-avds
# 应打出你刚建的名字
```

也可以先不经过平台、自己开一次看能不能亮：

```bash
emulator -avd Medium_Phone_API_36.1
```

开着的话，`adb devices` 里会出现 `emulator-5554`。平台照样认成 READY，不必再点启动。

### 3. 进设备池的时间线

```
点启动 → BOOTING（30～60 秒）→ adb 认到 → 扫描（约 5 秒一轮）→ 设备表里出现
```

`state` 变成 READY 之后，设备表最多再等一轮扫描。别刚点启动就在表里找。

## 三、iOS（Simulator）

### 1. 装 Xcode

App Store 装 **Xcode**，打开一次点过协议，再：

```bash
xcode-select -p
# 应是 /Applications/Xcode.app/Contents/Developer

xcrun simctl list runtimes
# 至少有一条 iOS runtime
```

没有 runtime：Xcode → Settings → Platforms，下载对应 iOS。

### 2. 要有哪些模拟器

Xcode 装完一般自带 iPhone / iPad。查看：

```bash
xcrun simctl list devices available
```

没有的话：Xcode → **Window → Devices and Simulators → Simulators → +**。设备池会列出所有 **iPhone / iPad**（不管 Watch / TV）。

### 3. 启动

设备池里点「启动」，或本机：

```bash
xcrun simctl boot <UDID>
open -a Simulator --args -CurrentDeviceUDID <UDID>
```

`simctl list` 里状态是 **Booted** 之后，扫描会把它收进设备池，名字带「（模拟器）」，`isEmulator=true`，默认测试环境。

清数据 = `simctl erase` 再开机，不要只关机。

### 4. 和真机的差别

| | Simulator | 真机 |
| --- | --- | --- |
| 怎么被发现 | `xcrun simctl` | `idevice_id`（USB） |
| 启停 | 设备池 / simctl | 插线、信任 |
| 自动化 | Appium 在模拟器上自己编 WDA（第一次会慢） | 本机 WDA + iproxy + 开发者签名 |
| 生产 / 性能 | 同样拦住 | 可以 |

真机还要：`brew install libimobiledevice ideviceinstaller`，手机信任这台电脑，WDA 的 Team / Bundle 配在后端配置里。

## 四、鸿蒙（DevEco Emulator）

### 1. 装 DevEco Studio

装 [DevEco Studio](https://developer.huawei.com/consumer/cn/deveco-studio/)，打开一次，SDK 勾选 **HarmonyOS SDK** 和 **Toolchains**。hdc 和 Emulator 常见路径：

```text
/Applications/DevEco-Studio.app/Contents/sdk/default/openharmony/toolchains/hdc
/Applications/DevEco-Studio.app/Contents/tools/emulator/Emulator
```

不要把 Android SDK 里那个也叫 `Emulator` 的二进制当成鸿蒙的。平台只认 DevEco 这条路径。

第一次先签协议（非交互）：

```bash
/Applications/DevEco-Studio.app/Contents/tools/emulator/Emulator -license accept
```

### 2. 下镜像、建实例

本机还没有镜像时，`Emulator -list` 是 `[Empty]`。先下 Phone 镜像（几十分钟、要网络）：

```bash
EMU=/Applications/DevEco-Studio.app/Contents/tools/emulator/Emulator
"$EMU" -imageList -downloaded true
"$EMU" -install -deviceType Phone -osVersion "HarmonyOS 6.1.1(24)"
"$EMU" -create Phone -deviceType Phone -osVersion "HarmonyOS 6.1.1(24)"
"$EMU" -list
```

也可以在 DevEco → **Device Manager** 里点创建，或镜像下完后跑：

```bash
bash scripts/harmony/setup_emulator.sh
```

设备池认的是实例名（例如 `Phone`），启动、关闭、清数据都用这个名字。

### 3. 启动

设备池里点「启动」，或本机：

```bash
"$EMU" -start Phone
# 干净环境（清数据）
"$EMU" -start Phone -bootmode reset
hdc list targets
# 起来之后常见序列号：127.0.0.1:5555
```

`hdc` 认到环回地址之后，扫描会把它收进设备池，名字带「（模拟器）」，`isEmulator=true`，默认测试环境。USB 畅享那种序列号**不会**被标成模拟器。

清数据 = `-bootmode reset` 再开机，不要只关机。

### 4. 和真机的差别

| | Emulator | 真机 |
| --- | --- | --- |
| 怎么被发现 | `Emulator -list` + `hdc` | `hdc list targets`（USB / 无线） |
| 启停 | 设备池 / `Emulator -start` `-stop` | 插线、信任 |
| 自动化 | 同一套 hdc + hmdriver2 | 同一套 |
| 生产 / 性能 | 同样拦住 | 可以 |

无线真机是局域网 `ip:port`，不是 `127.0.0.1`。平台只把环回地址当成模拟器，避免把真机拦出生产。

## 五、真机（可选，和虚拟机共用一台主控机）

- **Android**：USB 调试打开，`adb devices` 为 `device`。无线调试是 `host:port`，平台能扫到。
- **iOS**：线连上、点信任，`idevice_id -l` 能打出 UDID。
- **鸿蒙**：开发者选项里打开 USB 调试（hdc），`hdc list targets` 能打出序列号。无线是 `hdc tconn ip:port`。
- 坏了或维护中：设备表里**停用**，不要拔线装成「设备丢了」。

## 六、装完怎么验收

按顺序跑，全绿再让组里用。

```bash
# 1. 命令
which adb emulator xcrun hdc
emulator -list-avds
xcrun simctl list devices available | head
/Applications/DevEco-Studio.app/Contents/tools/emulator/Emulator -list

# 2. 本机先能开
emulator -avd <你的AVD名>          # 另开一个终端
xcrun simctl boot <某个 iPhone UDID>
open -a Simulator
/Applications/DevEco-Studio.app/Contents/tools/emulator/Emulator -start Phone

# 3. 连上
adb devices -l
hdc list targets
# 应有 emulator-5554 / 127.0.0.1:5555 或 真机序列号

# 4. 重启后端，打开平台 → 资产管理 → 设备池
```

设备池应能看到：

- Android 那一行，平台标 Android，开着则 READY
- iPhone / iPad 若干行，平台标 iOS
- 鸿蒙 `Phone` 一行，平台标 HarmonyOS
- 右上角 **开着 n / 上限**

下方设备表：已开机的虚拟机和真机在一起，模拟器有橙色标签，新虚拟机环境默认「测试」。

再随便跑一条**测试环境**试跑（自动分配、允许模拟器）。试跑弹窗会写「跑在哪台」，左边是当前屏幕，不是本机弹出的模拟器窗口——窗口在主控机桌面上。

## 七、日常就这几下

1. 主控机常开，后端常开。虚拟机保持 READY，当固定成员。
2. 组里跑自动化：执行时默认「自动分配」，不用自己挑机。
3. 要点选 / 调试：设备池里**借用**（和任务同一把锁）。VIEWER 只能看，启停和借用要 TESTER 及以上。
4. 脏了：点「清数据」，不要关。
5. 内存紧或卡死：确认没人占用（`busy` 时关闭是灰的），再关。

启动后不要立刻去设备表里找。READY 之后最多再等 5 秒扫描。

## 八、常见问题

**设备池提示找不到 emulator 命令**  
SDK 没装，或后端进程看不到。查 `~/Library/Android/sdk/emulator/emulator` 在不在，给后端配 `ANDROID_HOME`，**重启后端**。

**有 AVD / 模拟器，设备表是 0**  
没开机。上方列表里是「主控机装了什么」，下面表是「adb / simctl / hdc 已经连上什么」。先启动。

**点了启动，表里还没有**  
BOOTING 要 30～60 秒（iOS 大约 20～40 秒，鸿蒙大约 40～90 秒），之后还要一轮扫描。看上方状态，别刷新狂点——再点一次是幂等的，但人会以为失败了。

**模拟器 0，但表里有 emulator-5554**  
老数据 `is_emulator` 可能是空的。刷新设备；平台也会把 `emulator-` 前缀当成模拟器。雷电是 `127.0.0.1:5555`，要靠扫描读 `getprop`，读不到就故意不算，避免把真机拦出生产。

**iOS 真机扫不到**  
`idevice_id -l` 为空：线、信任、是否锁着。Simulator 不走这条命令。

**第一次在 Simulator 上跑流程很慢**  
Appium 在给这台编 WDA，等一次即可。真机仍走原来的签名安装。

**APP 在模拟器上闪退**  
常见是 ABI（必须 arm64 包配 arm64 镜像）、缺 Play 服务、或包自己的模拟器检测。本机可先跑 `scripts/try_emulator.sh` 看安装和进程还在不在。

**鸿蒙模拟器列表是空的**  
镜像没下，或没建实例。`Emulator -imageList -downloaded true` 应能看到 Phone；没有就 `-install`，再 `-create Phone`。许可没签会拦启动：`Emulator -license accept`。

**畅享真机被标成模拟器**  
不该发生。平台只认 `127.0.0.1:` / `localhost:` 或目录对上的实例。若真标错了，先看 `hdc list targets -v` 是不是 USB。
