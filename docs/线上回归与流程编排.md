# 线上回归与流程编排

## 唯一真相：`ui_flows`

APP UI 自动化（测试任务 / 线上回归）都来自 `ui_flows` 表。线上回归页**不再**维护「功能 1～7」硬编码清单。

## catalog 约定

| catalog | 用途 |
|---------|------|
| `ONLINE` | 仅出现在「APP 线上回归」勾选列表（UI 功能） |
| `SHARED` | UI 功能：测试编排与线上回归共用（**不含** App 性能测试） |
| `AUTOMATION` | 仅 UI 测试任务 / 流程执行，**不**进回归页 |
| `PERFORMANCE` | **仅** App 应用程序性能测试选流程，与 UI 功能流程隔离 |

同时需满足：

- `is_component = false`（组件只被 `CALL_COMPONENT` 引用）
- `enabled = true`
- `platform` 与回归设备匹配
- `app_id`：有值则仅该 APP 可见；**空 + SHARED** = 真·通用（如卸装启动，各 APP 可见）；**空 + ONLINE** = 历史遗留，仅国内电竞可见（海外不会误展示完美电竞用例）

`sort_order`（默认 100）：回归页**用例卡片列表**的展示顺序，越小越靠前。实际执行顺序以用户勾选先后为准（请求里 `flowIds` 的数组顺序）。

卸装/启动目标包：执行时用回归 job 的 `uiAppId`（或任务 config），从**应用字典**解析包名。步骤参数里若写死 `appId`/`packageName` 会覆盖，通用流程请留空。

## API

- 列表：`GET /ui-flows?forRegression=true&appId=DOMESTIC_ESPORTS`
- 启动：`POST /online-regression/runs`，body 含 `flowIds: string[]`（兼容旧 `featureIds` 一两个版本）

## 装包关键字

在流程步骤中使用（不必改回归页代码）：

| 关键字 | 行为 |
|--------|------|
| `UNINSTALL_APP` | 未安装跳过；已安装则卸载 |
| `INSTALL_APP` | **多方式安装**（推荐） |
| `INSTALL_FROM_STORE` | 兼容旧名，默认等同 `CHANNEL_PAGE` |
| `LAUNCH_APP` | **启动应用 · Android**（force-stop 后启，偏冷启） |
| `LAUNCH_APP_IOS` | **启动应用 · iOS**（Appium + WDA，`forceAppLaunch`） |
| `COLD_START` | **冷启动 · Android**：force-stop 后再启，日志记录耗时 |
| `COLD_START_IOS` | **冷启动 · iOS**：terminateApp 后再启，日志记录耗时 |
| `HOT_START` | **热启动 · Android**：不杀进程；Home 进后台后再拉回，记耗时 |
| `HOT_START_IOS` | **热启动 · iOS**：不杀进程；Home 进后台后 activate，记耗时 |

种子流程 `flow-install-verify-android` = 卸 → `INSTALL_APP(CHANNEL_PAGE)` → 启动，`app_id` 空（通用），`sort_order=90`。

### 安装方式 `installMode`（Android 先）

| 模式 | 说明 | 关键参数 |
|------|------|----------|
| `CHANNEL_PAGE` | 打开渠道/商店详情页再点安装（线上回归默认） | `channelUrl` 可选；否则 `ui_apps.channel_urls`；再否则厂商默认 URI |
| `PGYER` | 蒲公英 build 下载或 URL 下载后 adb 安装 | `pgyerBuildKey` 或 `pgyerUrl`（需 `pgyer.enabled=true`） |
| `LOCAL_APK` | 已上传包 / 服务器路径 | `apkArtifactId`（applications.id）或 `apkPath` |
| `QR_ASSIST` | 执行日志展示二维码，人工扫码；后端轮询包名 | `qrPayload`（https 安装页） |

任务 / 回归 config 的 `params.installMode` 可覆盖步骤默认。iOS 暂仅 `CHANNEL_PAGE`（App Store）。

迁移渠道 URL 列：

```bash
mysql ... < src/main/resources/db/migration_ui_apps_channel_urls.sql
```

`ui_apps.channel_urls` 示例：

```json
{"XIAOMI":"https://...","HUAWEI":"https://...","OPPO":"https://...","VIVO":"https://..."}
```

### Android 渠道页点击策略

国内 Android **按 `ro.product.manufacturer` 打开对应应用市场**（小米 / 华为 / 荣耀 / OPPO / vivo / 三星），海外 Pog 走 Google Play。成功判定仍是目标包名落地。

点击「安装」优先级：

1. **uiautomator 文案**（安装 / 下载 / 升级…）
2. **设备 `config` 校准**：`{"installTapX":900,"installTapY":2100}`
3. **`app.install.vendor-tap.<厂商>`**
4. **全局** `android-tap-x/y`（`tapMode=FIXED_FALLBACK`）

注意：真机需已登录对应应用市场账号；不解析渠道号 / umeng。

## 种子流程（见 `seed_online_regression_flows.sql`）

| id | 说明 | 默认启用 |
|----|------|----------|
| `flow-login-logout-android` | 登录退出 | 是 |
| `flow-install-verify-android` | 安装验证 | 是 |
| `flow-browse-*-android` | 赛事/活动/资讯/评论/广场 | **否**（编排完成后再启用） |

## 迁移

```bash
# sort_order 列
mysql ... < src/main/resources/db/migration_ui_flows_sort_order.sql
# 应用字典渠道页 URL
mysql ... < src/main/resources/db/migration_ui_apps_channel_urls.sql
# 种子流程
mysql ... < src/main/resources/db/seed_online_regression_flows.sql
```

重启后端以种子新关键字 `INSTALL_APP`（或执行 seed SQL 中的 `ui_keywords` 段）。
