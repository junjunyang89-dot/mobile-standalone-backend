# 按业务选取的审查重点

## 需求与跨项目

- 角色权限、主路径/失败路径、规则矛盾、数量与金额单位、边界时间、历史数据和新老规则适用范围。
- H5/Android/iOS/Electron 与服务端字段、枚举、错误码、登录身份、签名、分页、版本兼容和重试行为。
- 跳转、后台切前台、重复点击、断网重连、消息晚到、用户切换、状态刷新；纯前端变更也可能影响老接口参数。
- 多服务的调用身份、超时预算、错误传播、同步与异步状态、补偿责任及最终对账。

## 后端与接口

- 身份校验是否覆盖正常、幂等、缓存命中、终态重试、补偿和管理入口；不能只看有无登录注解。
- 参数必填/类型/范围/组合约束、业务归属、数量溢出、金额精度、批量部分成功、分页稳定性。
- 幂等键作用域、并发唯一性、锁粒度/续期/释放、事务提交前后副作用、失败恢复。
- 状态迁移与唯一赢家；成功是否可回退、失败可否重试、渠道成功而本地失败如何收敛。
- 定时任务时间窗、任务饥饿、固定取前 N 条、重试上限、死信、延迟/重复/乱序消息。
- 缓存失效与事务时序、身份隔离、缓存失败计数、TTL、热键、空值缓存、旧缓存兼容。
- Redis/ES/MySQL 与外部渠道之间的一致性、读写延迟、回源及故障降级；Apollo 配置变更的默认值和生效范围。

## 数据库

DDL 只是结构依据，不证明部署成功或已有真实数据。结合调用 SQL、实体/Mapper 和读写路径看：

- 唯一键与业务幂等一致、NULL/空字符串行为、联合索引顺序、大小写/排序规则、字段长度、金额单位和时间精度。
- 事务边界、隔离级别假设、锁顺序、库存超卖、更新条数为零、批处理部分失败。
- 新老版本兼容、默认值、回填、枚举新增、历史订单快照、敏感字段脱敏。
- 性能风险给出触发量级和查询路径。没有执行计划和数据分布时不要断言索引一定无效或 SQL 一定超时。

## 最容易误报的地方

名称推断不是业务语义。例如组 ID 可能经产品约定同时表示箱数；应确认规则及配置约束，再审数量、库存比例与向下取整。若确认会推翻旧风险，更新该风险和关联用例，不继续把旧假设当缺陷。

重复请求返回其他用户的结果，不自动等于能转走他人权益；分别追踪信息暴露和实际写操作的归属校验。

探针依赖替身且未连接渠道时，只能证明原方法在指定输入下的行为，不证明部署环境存在同样状态。
